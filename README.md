## 🎬 Core Features

- **Age Stratification Heuristics:** Maps viewer age boundaries (Children, Teen, Young Adult, Adult, Mature) to verified movie ratings and genres.
- **Interactive Theater Aesthetics:** Cinema-themed dark mode styling with smooth hover transitions and dynamic posters.
- **Instant Input Evaluation:** Real-time form listeners delivering recommendations without requiring full-page reloads.
